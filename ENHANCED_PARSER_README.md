# 🚀 Улучшенный парсер похожих товаров

## 📋 Описание

Новый парсер для сбора визуально похожих товаров с Lamoda с использованием кнопки "Визуально" и прокрутки карусели. Парсер собирает до 24 похожих товаров с одного исходного товара.

## 🎯 Особенности

### ✅ Новые возможности
- **Кнопка "Визуально"**: Находит и нажимает на кнопку "Визуально" в разделе похожих товаров
- **Прокрутка карусели**: Автоматически прокручивает карусель для получения всех 24 товаров
- **Новая коллекция**: Сохраняет товары в коллекцию `products_enhanced`
- **Улучшенная логика**: Использует лучшие практики из существующих парсеров

### 🔄 Алгоритм работы
1. **Загрузка товара**: Переходит на страницу исходного товара
2. **Поиск раздела**: Находит раздел "Похожие товары"
3. **Кнопка "Визуально"**: Нажимает на кнопку "Визуально"
4. **Сбор товаров**: Собирает 6 товаров из первой группы
5. **Прокрутка**: Нажимает на стрелку для получения следующей группы
6. **Повтор**: Повторяет 4 раза для получения всех 24 товаров
7. **Парсинг**: Парсит каждый найденный товар
8. **Сохранение**: Сохраняет в новую коллекцию MongoDB

## 🐛 Отладка

### Логи
Парсер выводит подробные логи:
- `🔍` - Поиск элементов
- `✅` - Успешные операции
- `❌` - Ошибки
- `⚠️` - Предупреждения

### Частые проблемы

#### 1. Браузер не подключен
```
❌ Ошибка подключения к браузеру
```
**Решение**: Убедитесь, что Chrome запущен с `--remote-debugging-port=9222`

#### 2. Кнопка "Визуально" не найдена
```
❌ Кнопка 'Визуально' не найдена
```
**Решение**: Проверьте, что страница загрузилась полностью

#### 3. MongoDB не подключена
```
❌ Ошибка подключения к MongoDB
```
**Решение**: Убедитесь, что MongoDB запущена и доступна
