# Система автоматического создания подписки после оплаты

Эта система автоматически создает предварительную подписку в базе данных после успешной оплаты через CloudPayments.

## Как это работает

1. **Пользователь оплачивает подписку** через кнопку "Купить подписку" на сайте
2. **CloudPayments отправляет webhook** на `/paid_callback` с данными об оплате
3. **Система определяет тип покупки** по описанию и дополнительным данным
4. **Создается предварительная подписка** в коллекции `pre_subscriptions` с датой окончания через 1 год
5. **Пользователь получает доступ** к функциям ИИ-стилиста сразу после оплаты

## Определение типа покупки

Система определяет покупку подписки по следующим критериям:

- **Описание платежа** содержит слова "подписк" или "предзаказ"
- **Поле `type`** в данных CloudPayments равно "subscription"
- **Поле `type`** в JSON данных равно "subscription"

## Структура данных webhook'а

```json
{
    "Status": "Completed",
    "Email": "user@example.com",
    "Description": "ИИ-стилист (годовая подписка)",
    "Data": "{\"email\":\"user@example.com\",\"type\":\"subscription\"}"
}
```

## Обработка в `/paid_callback`

### Для подписок:
1. Подключение к MongoDB
2. Установка даты окончания подписки (текущая дата + 1 год)
3. Создание записи в коллекции `pre_subscriptions`
4. Возврат успешного ответа

### Для гайдов:
1. Генерация PDF
2. Отправка email с гайдом
3. Возврат успешного ответа

## Коды ответов

- `0` - Успешная обработка
- `10` - Отсутствует email
- `11` - Файл не найден
- `12` - Ошибка отправки email
- `13` - Платеж не завершен
- `14` - Ошибка обработки
- `15` - Ошибка подключения к БД
- `16` - Ошибка добавления подписки
- `17` - Ошибка обработки подписки

## Логирование

Все операции логируются с префиксом `[paid_callback]`:

```
[paid_callback] Processing subscription purchase
[paid_callback] Subscription added successfully for user@example.com
```

## Настройка стоимости подписки

Стоимость подписки настраивается через переменные окружения:

```bash
# Обычная стоимость подписки
SUBSCRIPTION_PRICE=4990.00

# Специальная стоимость для владельцев гайдов
SUBSCRIPTION_PRICE_SPECIAL=4490.00
```

### Значения по умолчанию:
- `SUBSCRIPTION_PRICE`: 4990.00 руб
- `SUBSCRIPTION_PRICE_SPECIAL`: 4490.00 руб

### Изменение стоимости:
1. Отредактируйте файл `.env`
2. Измените значения переменных
3. Перезапустите приложение
