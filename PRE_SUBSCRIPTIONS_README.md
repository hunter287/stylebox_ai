# Система предварительных подписок

Эта система позволяет автоматически присваивать подписку пользователям при регистрации, если их email был заранее добавлен в список предварительных подписок.

## Как это работает

1. **Добавление предварительных подписок**: Администратор добавляет email'ы и даты окончания подписок в коллекцию `pre_subscriptions` в MongoDB
2. **Автоматическое присвоение**: Когда пользователь регистрируется с email'ом из списка предварительных подписок, подписка автоматически присваивается его аккаунту
3. **Очистка**: Предварительная подписка удаляется из коллекции после присвоения пользователю

## API Endpoints

### Добавить предварительную подписку
```
POST /admin/pre_subscriptions
Content-Type: application/json

{
    "email": "user@example.com",
    "subscription_end": "2025-12-31",
    "source": "manual",
    "notes": "Тестовый пользователь"
}
```

### Получить список предварительных подписок
```
GET /admin/pre_subscriptions?active_only=true
```

### Удалить предварительную подписку
```
DELETE /admin/pre_subscriptions/user@example.com
```

### Очистить истекшие подписки
```
POST /admin/pre_subscriptions/cleanup
```

### Проверить предварительную подписку
```
GET /admin/pre_subscriptions/check/user@example.com
```

## Утилита командной строки

Запустите скрипт для интерактивного управления предварительными подписками:

```bash
python add_pre_subscriptions.py
```

### Возможности утилиты:

1. **Добавить одну подписку** - интерактивный ввод данных
2. **Добавить несколько подписок из файла** - массовое добавление из CSV файла
3. **Показать список подписок** - просмотр всех активных предварительных подписок
4. **Очистить истекшие подписки** - автоматическая очистка

### Формат CSV файла:

```csv
# email,дата_окончания,источник,заметки
user1@example.com,2025-12-31,manual,Тестовый пользователь 1
user2@example.com,2025-11-30,google_sheets,Импорт из Google Sheets
user3@example.com,2025-10-15,payment,Оплаченная подписка
```

## Структура данных

### Коллекция `pre_subscriptions` в MongoDB:

```javascript
{
    "_id": ObjectId("..."),
    "email": "user@example.com",
    "subscription_end": ISODate("2025-12-31T00:00:00Z"),
    "is_active": true,
    "source": "manual", // manual, google_sheets, payment, referral
    "notes": "Тестовый пользователь",
    "created_at": ISODate("2024-01-01T10:00:00Z"),
    "updated_at": ISODate("2024-01-01T10:00:00Z")
}
```

### Поле `subscription_end` в коллекции `users`:

```javascript
{
    "_id": ObjectId("..."),
    "email": "user@example.com",
    "subscription_end": ISODate("2025-12-31T00:00:00Z"), // Автоматически присваивается при регистрации
    // ... другие поля пользователя
}
```

## Процесс регистрации

1. Пользователь отправляет запрос на регистрацию с email и паролем
2. Система проверяет наличие предварительной подписки для этого email
3. Если подписка найдена и не истекла:
   - Создается пользователь с полем `subscription_end`
   - Предварительная подписка удаляется из коллекции `pre_subscriptions`
   - Возвращается сообщение "Регистрация успешна (подписка активирована)"
4. Если подписка не найдена:
   - Создается пользователь без подписки
   - Возвращается обычное сообщение об успешной регистрации

## Безопасность

- Все API endpoints для управления предварительными подписками находятся под `/admin/` и должны быть защищены
- Email'ы нормализуются (приводятся к нижнему регистру)
- Проверяется валидность дат
- Истекшие подписки автоматически помечаются как неактивные

## Логирование

Все операции с предварительными подписками логируются:

```
🔑 Найдена предварительная подписка для user@example.com, действует до 2025-12-31
✅ Предварительная подписка перенесена в аккаунт пользователя: user@example.com
✅ Предварительная подписка добавлена: user@example.com
```

## Примеры использования

### Добавление подписки через API:

```bash
curl -X POST http://localhost:5001/admin/pre_subscriptions \
  -H "Content-Type: application/json" \
  -d '{
    "email": "test@example.com",
    "subscription_end": "2025-12-31",
    "source": "manual",
    "notes": "Тестовый пользователь"
  }'
```

### Проверка подписки:

```bash
curl http://localhost:5001/admin/pre_subscriptions/check/test@example.com
```

### Массовое добавление из файла:

```bash
python add_pre_subscriptions.py
# Выберите опцию 2 и укажите путь к CSV файлу
```
