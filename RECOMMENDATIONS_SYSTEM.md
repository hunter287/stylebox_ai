# Система персональных рекомендаций

## 🎯 Обзор

Система автоматически подбирает 10 идеальных вещей для каждого клиента на основе:
- Анализа цветотипа и типажа внешности
- Предпочтений стиля и цветовой гаммы
- Размеров и типа фигуры
- Нужных категорий одежды

## 🔧 Архитектура

### **Гибридный подход:**
1. **Первичная фильтрация** (MongoDB) - отсеивание по базовым критериям
2. **LLM ранжирование** (OpenAI GPT-4) - выбор лучших 10 вещей с объяснениями

### **Преимущества:**
- ✅ Скорость (не анализируем всю БД через LLM)
- ✅ Качество (LLM делает финальный выбор)
- ✅ Объяснимость (почему выбрана каждая вещь)
- ✅ Масштабируемость

## 📊 Процесс подбора

### **1. Сбор данных из анкеты:**
```javascript
{
  "color_type": "мягкое лето",
  "kibbe_type": "Романтик", 
  "body_type": "песочные часы",
  "style_preferences": ["casual", "feminine"],
  "color_preferences": ["soft", "neutral"],
  "sizes": {"top": "M", "bottom": "42", "foot": "38"},
  "needed_items": ["dresses", "blouses", "jeans"]
}
```

### **2. Первичная фильтрация:**
- Размеры (верх, низ, обувь)
- Категории одежды
- Базовые критерии соответствия

### **3. LLM анализ:**
```python
prompt = f"""
Ты - эксперт по стилю. Подбери 10 лучших вещей для клиента.

ДАННЫЕ КЛИЕНТА:
- Цветотип: {color_type}
- Типаж Кибби: {kibbe_type}
- Тип фигуры: {body_type}
- Предпочтения стиля: {style_prefs}
- Цветовая гамма: {color_prefs}
- Размеры: верх {top_size}, низ {bottom_size}, ноги {foot_size}

ДОСТУПНЫЕ ВЕЩИ:
{products_json}

ЗАДАЧА:
1. Проанализируй каждую вещь по критериям:
   - Соответствие цветотипу
   - Соответствие типажу Кибби
   - Соответствие типу фигуры
   - Соответствие стилю
   - Соответствие размерам
   - Качество и цена

2. Выбери 10 лучших вещей

3. Верни JSON массив с выбранными вещами
"""
```

### **4. Отображение результатов:**
- Сетка 2x5 карточек товаров
- Фото, название, бренд, цена, описание
- Кнопка перехода к товару
- Адаптивный дизайн для мобильных

## 🛠️ Техническая реализация

### **Backend (Flask):**
- `/get_recommendations` - основной эндпоинт
- `get_products_for_recommendations()` - фильтрация из MongoDB
- `rank_products_with_llm()` - LLM ранжирование
- `create_recommendation_prompt()` - создание промпта

### **Frontend (JavaScript):**
- `getRecommendations()` - запрос рекомендаций

## 📈 Критерии оценки

### **LLM анализирует по шкале 1-10:**
1. **Соответствие цветотипу** (3 балла)
2. **Соответствие типажу Кибби** (2 балла)
3. **Соответствие типу фигуры** (2 балла)
4. **Соответствие стилю** (1 балл)
5. **Соответствие размерам** (1 балл)
6. **Качество и цена** (1 балл)

### **Финальный выбор:**
- Топ-10 вещей по общему баллу
- Разнообразие категорий
- Сбалансированность по цене

## 🔄 Workflow

1. **Завершение анкеты** → `completeSurvey()`
2. **Сохранение в JSON** → `saveSurveyToFile()`
3. **Запрос рекомендаций** → `getRecommendations()`
4. **Фильтрация товаров** → MongoDB query
5. **LLM ранжирование** → OpenAI GPT-4
6. **Отображение результатов** → `showRecommendations()`
